# Master's Thesis Project: Direct Interface Circuits for Resistive Sensors

Master's Thesis project focused on the design and implementation of one-, two-, and three-point calibration methods for MCU direct interface circuits for resistive sensors.

## Aim

The project aims to design and implement a laboratory setup capable of comparing three calibration methods for DIC resistive sensors, taking measurements, and analyzing acquired data. Key milestones include:
- Comprehensive review of measurement methods for resistive sensors
- Designing a laboratory setup including a custom PCB
- Setup assembly
- Writing firmware for test MCUs
- Making a PC app managing data aqusition and storage
- Gathering experimental data regarding three calibration methods
- Analyzing experimental data and drawing conclusions

## Structure

The repository is structured as follows:
- [`/docs`](./docs/) – Research notes, analysis scripts, and useful reference material
- [`/firmware`](./firmware/) – MCU firmware source code
- [`/hardware`](./hardware/) – Hardware design files including custom PCB and 3D printed case
- [`/software`](./software/) - PC data acquisition app source code
- [`/thesis`](./thesis/) – LaTeX source files for the thesis document
